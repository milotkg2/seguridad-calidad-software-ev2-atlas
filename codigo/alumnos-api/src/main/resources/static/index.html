API de Alumnos

Microservicio base para la gestión de alumnos (CRUD) construido con Spring Boot, arquitectura limpia y SQLite. Servirá como punto de partida para los siguientes módulos del curso.

Spring Boot 3 Java 21 Maven SQLite OpenAPI Arquitectura limpia

Endpoints

Método Ruta Descripción
GET /api/v1/alumnos Lista todos los alumnos
GET /api/v1/alumnos/{id} Obtiene un alumno por su id
POST /api/v1/alumnos Crea un nuevo alumno
PUT /api/v1/alumnos/{id} Actualiza un alumno existente
DELETE /api/v1/alumnos/{id} Elimina un alumno

Cómo probarlo

Crear un alumno:

curl -X POST http://localhost:8080/api/v1/alumnos \
  -H "Content-Type: application/json" \
  -d '{"rut":"12.345.678-9","nombres":"Ana","apellidos":"Pérez",
       "email":"ana.perez@duocuc.cl","carrera":"Ingeniería en Informática","edad":21}'

Listar alumnos:

curl http://localhost:8080/api/v1/alumnos
